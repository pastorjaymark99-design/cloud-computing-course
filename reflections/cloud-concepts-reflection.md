 # Cloud Concepts Reflection

Cloud computing has become an important part of my daily life because many of the applications I use rely on cloud services. Three cloud services that I use regularly are Google Drive, Facebook Messenger, and Canva. These applications help me complete school tasks, communicate with others, and create presentations and documents more efficiently.

Google Drive is classified as Software as a Service (SaaS) because it allows users to store, manage, and share files through a web browser without installing or managing servers. It uses a **Public Cloud** deployment model because it is available to anyone with a Google account. Facebook Messenger is also an example of **Software as a Service** since it provides online messaging services that users can access through the internet. It is also deployed on a **Public Cloud** because millions of users worldwide can use the service. Canva is another **Software as a Service** application because it provides online graphic design tools without requiring users to install professional software. Like Google Drive and Messenger, Canva operates on a **Public Cloud**.

Git and GitHub are essential tools for cloud projects because they help developers manage changes in their files and collaborate effectively. Git records every change made to a project, making it easy to review previous versions or restore files if mistakes happen. GitHub allows team members to work on the same project without overwriting each other's work. It also helps track updates, review contributions, and organize project development.

Through this activity, I realized that cloud computing is not only used by businesses but is also a part of my everyday life. Understanding cloud service models, deployment models, and version control has helped me appreciate how modern applications work and how developers collaborate efficiently to build reliable cloud-based systems.
